# Казначейский терминал

Веб-интерфейс для казначейства: собирает рыночные данные из открытых источников
(Московская биржа, Банк России, НРД) и превращает их в метрики, на которые можно
опереться при принятии решений — цены, торговые объёмы, ликвидность, доходности,
премии к безрисковой кривой, дюрация портфеля и календарь выплат.

Данные реальные: терминал ходит в открытые API напрямую, без ключей и регистрации.

## Что внутри

**Обзор рынка** — ключевая ставка, RUONIA, курсы ЦБ, индексы МосБиржи и RGBI,
суммарный оборот сессии, кривая бескупонной доходности и динамика ставок.

**Инструменты** — витрина по всем торгуемым бумагам: цена, изменение, оборот,
объём, число сделок, спред и сводная оценка ликвидности 0–100.

**Облигации** — подбор выпусков по доходности, дюрации и обороту с расчётом
премии к кривой бескупонной доходности на дюрации выпуска.

**Анализ облигаций** — развёрнутая витрина по всем торгуемым выпускам: НКД,
средневзвешенная цена предыдущего дня, полная («грязная») цена и сумма к оплате
за бумагу, доходность к погашению и текущая доходность, премия к КБД и Z-спред,
дюрация, тип купона, амортизация, оферта, ликвидность и расчётная оценка риска.
Фильтры — по доходности, дюрации, окну погашения, типу купона, валюте, уровню
листинга, наличию оферты и амортизации. Таблица выгружается в Excel или CSV.

**Выгрузка** — вставьте список бумаг прямо из Excel (ISIN или тикеры, столбцом
или через запятую), задайте период и отметьте нужные параметры. Терминал сам
найдёт бумаги на бирже — включая те, которых ещё нет в локальной базе, — и
соберёт таблицу в одной из двух форм: построчно по датам (как таблица торгов на
сайте MOEX) или сводом за период. Результат выгружается обратно в Excel или CSV.

**Портфель** — позиции методом средней цены, реализованный и нереализованный
результат, дюрация и доходность облигационной части, концентрация (индекс
Херфиндаля, доля топ-5) и переоценка при сдвиге ставок.

**Сигналы** — аномалии торговых объёмов, широкие спреды у ликвидных бумаг,
резкие движения цены и ближайшие купоны, амортизации и оферты.

**Оформление** — тёмная и светлая темы в еловых тонах, переключатель в шапке.
Выбор запоминается; при первом открытии терминал следует настройке системы.

**Источники** — что берётся из каждого источника и журнал всех запусков сбора.

## Быстрый старт

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Терминал: <http://127.0.0.1:8000> · документация API: <http://127.0.0.1:8000/docs>

При первом запуске приложение само сходит за данными (полный цикл занимает
около 15 секунд) и дальше обновляет котировки раз в 5 минут, справочники и
кривую — раз в час.

## Источники данных

| Источник | Что берём | Доступ |
|---|---|---|
| **MOEX ISS** | цены, bid/ask, объёмы и число сделок, НКД, средневзвешенная цена, доходности, дюрация, G- и Z-спреды, тип купона, история торгов, кривая бескупонной доходности | открытый, без авторизации |
| **Банк России** | официальные курсы валют, ключевая ставка, RUONIA | открытый, без авторизации |
| **НРД** | график купонов, амортизации, оферты, даты фиксации реестра | см. ниже |

### О данных НРД

НРД не публикует бесплатный machine-readable API: Ценовой центр, ленты
корпоративных действий и справочник ISIN отдаются по договору. При этом
сведения о выпуске, которые эмитент раскрывает через НРД как расчётный
депозитарий, доступны публично через зеркало MOEX ISS — их терминал и
использует (`backend/app/sources/nsd.py`).

Если у организации есть договор с НРД, коммерческие ленты подключаются в том же
классе: задайте `TREASURY_NSD_API_KEY` и реализуйте `NsdSource.fetch_feed` —
сборщик, хранилище и аналитика останутся без изменений.

## Как читать метрики

**Оценка ликвидности (0–100)** — взвешенная свёртка оборота (45%), числа сделок
(30%) и относительного спреда (25%). Показывает, какой объём бумага примет без
заметного проскальзывания.

**Премия к КБД** — доходность выпуска минус доходность безрисковой кривой на его
дюрации, в базисных пунктах. Умеренная премия — плата за кредитный риск; премия
свыше 1000 бп (помечена ⚠) почти всегда означает проблемы у эмитента, а не
выгодную покупку.

**Аномалия объёма** — z-оценка последнего дневного объёма относительно
собственной истории бумаги. Всплеск объёма часто опережает движение цены.

**Чувствительность к ставке** — приближение первого порядка: ΔV ≈ −D × Δy × V.
Отвечает на вопрос «удлинять или сокращать дюрацию».

**НКД и полная цена** — облигации котируются в процентах от номинала, но
покупатель платит ещё и накопленный купонный доход. Терминал показывает НКД
отдельно, полную («грязную») цену в процентах и точную сумму к оплате за одну
бумагу — это то, что реально спишется по сделке.

**Средневзвешенная цена (СВЦ)** — цена, взвешенная по объёму сделок дня. Она
устойчивее цены закрытия и служит базой рыночной оценки. В терминале есть и СВЦ
предыдущего дня в текущем срезе, и СВЦ по каждому дню истории.

**Оценка риска** — расчётная величина из премии к кривой, уровня листинга и
ликвидности. Это **не** кредитный рейтинг: рейтинги АКРА и Эксперт РА в открытом
машиночитаемом виде не публикуются, поэтому терминал их не показывает и не
выдумывает. Премия свыше 5000 бп подписывается словами «дефолтный риск» — такие
цифры означают ожидания дефолта, а не доходность.

## Настройки

Переменные окружения с префиксом `TREASURY_` (или файл `.env`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TREASURY_DATABASE_URL` | `sqlite:///treasury.db` | хранилище (поддерживается PostgreSQL) |
| `TREASURY_COLLECT_ON_STARTUP` | `true` | собирать данные при запуске |
| `TREASURY_SCHEDULER_ENABLED` | `true` | фоновое обновление по расписанию |
| `TREASURY_QUOTES_INTERVAL_SEC` | `300` | период обновления котировок |
| `TREASURY_REFERENCE_INTERVAL_SEC` | `3600` | период обновления справочников и кривой |
| `TREASURY_HISTORY_DEPTH_DAYS` | `180` | глубина истории торгов |
| `TREASURY_MAX_INSTRUMENTS_PER_BOARD` | `0` | ограничение числа бумаг (0 — без ограничения) |
| `TREASURY_NSD_API_KEY` | — | ключ коммерческих лент НРД |

Схема базы обновляется сама: при запуске новой версии недостающие колонки
дописываются в существующую базу, данные при этом сохраняются.

## Тесты

```bash
cd backend && python -m pytest
```

Покрыты разбор ответов источников (включая пограничные случаи вроде дат ЦБ со
смещением и заглушек `0000-00-00`), расчёт ликвидности, интерполяция кривой,
детектор аномалий объёма, портфельная математика, разбор вставленного из Excel
списка бумаг, свод за период, типы файлов в .xlsx и CSV, классификация купонов
и оценка риска, а также все HTTP-эндпоинты.

## Ограничения

- Терминал считает по последнему собранному срезу, а не по потоку сделок:
  для внутридневного трейдинга он не предназначен.
- Оценка позиций ведётся в валюте котировки; мультивалютный портфель не
  приводится к рублю по курсу автоматически.
- Чувствительность к ставке линейна по дюрации и не учитывает выпуклость.
- Права доступа и аутентификация не реализованы — предполагается запуск во
  внутреннем контуре.
- Кредитные рейтинги агентств не показываются: в открытом машиночитаемом виде
  они не публикуются.
- Оценка риска и премия к кривой считаются по рыночным данным и не заменяют
  кредитный анализ эмитента.
