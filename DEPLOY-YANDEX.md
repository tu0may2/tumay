# Терминал на своём сервере в Яндекс Cloud

В отличие от туннеля с домашнего компьютера (см. `DEPLOY.md`), сервер в
облаке работает круглосуточно и не зависит от того, включён ли ваш ПК. Адрес
постоянный, портфель и сделки не пропадают при перезагрузке.

Взамен — это платно, и настройка идёт не двойным кликом, а через терминал
Linux по SSH. Ниже все шаги буквально, но какой-то опыт работы с командной
строкой облегчит жизнь.

## Сколько это стоит

Цены Yandex Cloud на август 2026 — проверяйте актуальные на
[странице тарифов](https://yandex.cloud/ru/prices) и в
[калькуляторе](https://yandex.cloud/ru/prices/calculator), они могут
измениться.

| Конфигурация | ВМ (compute) | Диск 20 ГБ | Публичный IP | Итого в месяц |
|---|---|---|---|---|
| **Экономная**: 2 vCPU (20% гарантии), 2 ГБ RAM, HDD | ≈ 1 250 ₽ | ≈ 42 ₽ | ≈ 110 ₽ | **≈ 1 400 ₽** |
| **С запасом**: 2 vCPU (100% гарантии), 2 ГБ RAM, SSD | ≈ 2 500 ₽ | ≈ 150 ₽ | ≈ 110 ₽ | **≈ 2 760 ₽** |

Терминалу для одного-двух пользователей достаточно экономной конфигурации:
он большую часть времени просто ждёт, обращаясь к бирже раз в 5–60 минут.
100% гарантия vCPU имеет смысл, только если вы дадите доступ многим смотрящим
одновременно.

**Плюс, если захотите свой адрес** (например `treasury.вашафамилия.ru`)
вместо голого IP — домен в зоне `.ru`: от ≈ 200 ₽/год. Без домена сайт всё
равно откроется, просто по IP-адресу и без «замочка» (HTTPS) в браузере.

**Новым аккаунтам обычно дают пробный грант** (в разных акциях — от 4 000 ₽
на 60 дней для физлиц). Он покрывает первый-полтора месяца экономной
конфигурации почти целиком. Условия действуют на момент регистрации — что
именно дадут вам, покажут в личном кабинете сразу после подтверждения.

## Что понадобится на вашем компьютере

1. **WinSCP** — бесплатная программа для копирования файлов на сервер,
   работает как проводник Windows: [winscp.net](https://winscp.net/eng/download.php).
2. Ничего для SSH ставить не нужно — командная строка Windows 10/11 умеет
   `ssh` из коробки.

## Шаг 1. Регистрация и оплата

1. Откройте [yandex.cloud](https://yandex.cloud), войдите под своим Яндекс ID
   (или заведите новый).
2. Подтвердите телефон и привяжите карту — без этого попробовать нельзя,
   но пока вы не создали ВМ, деньги не списываются.
3. Создайте **облако** и внутри него **каталог** (folder) — Yandex Cloud
   попросит это при первом входе, соглашайтесь с именами по умолчанию.

## Шаг 2. Создать виртуальную машину

1. В консоли слева — **Compute Cloud** → **Создать ВМ**.
2. **Образ**: Ubuntu 24.04 LTS (или 22.04 — обе подходят).
3. **Платформа и ресурсы**: Intel Ice Lake, 2 vCPU, гарантия 20%
   (`Скачок производительности` — обычная опция для бюджетного тарифа),
   2 ГБ RAM.
4. **Диск**: сетевой HDD или SSD, 20 ГБ.
5. **Сеть**: оставьте автоматический выбор подсети, обязательно включите
   **публичный IP-адрес** — без него снаружи не достучаться. По умолчанию он
   динамический (меняется, если ВМ перезапустить) — это нормально для начала.
6. **Доступ**: способ входа — **SSH-ключ**. Если ключа ещё нет, консоль
   предложит его сгенерировать и сразу даст скачать приватный файл (`.pem` или
   без расширения) — **сохраните его**, второй раз скачать нельзя. Логин
   пользователя оставьте `yc-user` или задайте свой.
7. Нажмите **Создать ВМ**, подождите минуту-две.
8. На странице готовой ВМ скопируйте **публичный IP-адрес** — он нужен на всех
   следующих шагах.

## Шаг 3. Подключиться по SSH

Откройте командную строку Windows (Win+R → `cmd`) и наберите:

```
ssh -i путь\к\скачанному\ключу yc-user@ВАШ_IP
```

При первом подключении спросит про отпечаток сервера — введите `yes`. Если
всё верно, увидите приглашение вида `yc-user@fhm-...:~$` — вы внутри сервера.

## Шаг 4. Загрузить код терминала

Проще всего через **WinSCP**:

1. Откройте WinSCP → «Новый сайт».
2. Тип: SFTP. Хост: ваш IP. Имя пользователя: `yc-user` (или как задали).
3. «Дополнительно» → «SSH» → «Аутентификация» → укажите файл приватного
   ключа (тот же, что для `ssh`; WinSCP предложит сконвертировать его в
   формат `.ppk` — соглашайтесь).
4. Подключитесь. Слева — ваш компьютер, справа — сервер.
5. Перетащите папку `treasure terminal/backend` (из архива, который вы уже
   распаковали) в домашнюю папку пользователя на сервере — получится
   `/home/yc-user/backend`.

## Шаг 5. Развернуть терминал одной командой

Вернитесь в окно `ssh` и выполните:

```
sudo bash /home/yc-user/backend/deploy/setup.sh /home/yc-user/backend
```

Скрипт сам поставит Python и nginx, заведёт отдельного системного
пользователя, создаст виртуальное окружение, установит зависимости и запустит
терминал как системную службу — она переживёт перезагрузку сервера и разрыв
SSH-сессии.

При первом запуске скрипт печатает пароль администратора — **запишите его**:
он же сохраняется в `backend/.env` на сервере, восстановить его иначе, кроме
как заглянуть в этот файл, нельзя (терминал хранит только хеш).

## Шаг 6. Открыть терминал наружу через nginx

Скрипт из шага 5 поднимает Python-сервер, но он слушает только сам себя
(`127.0.0.1`) — снаружи достучаться ещё нельзя, это сделано намеренно, чтобы
к серверу нельзя было обратиться в обход настроенного прокси.

```
sudo cp /home/yc-user/backend/deploy/nginx-treasury.conf /etc/nginx/sites-available/treasury
sudo sed -i "s/ВАШ_АДРЕС/ВАШ_IP_ИЛИ_ДОМЕН/" /etc/nginx/sites-available/treasury
sudo ln -s /etc/nginx/sites-available/treasury /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

Замените `ВАШ_IP_ИЛИ_ДОМЕН` на реальный адрес. Дальше в консоли Yandex Cloud
откройте вкладку ВМ → **Сетевые настройки** → группа безопасности → разрешите
входящий TCP-трафик на порт **80** (и 22, если ещё не разрешён, — для SSH).

Откройте `http://ВАШ_IP` в браузере — должна показаться форма входа.

## Шаг 7 (по желанию). Свой домен и HTTPS

Без этого шага сайт работает, но браузер пометит его как «Не защищено» —
для формы с паролем это не критично технически (данные внутри сети Yandex
Cloud), но выглядит тревожно и лучше не приучать себя вводить пароль на
таких страницах.

1. Купите домен (Reg.ru, Yandex 360 для бизнеса и другие регистраторы) и
   направьте A-запись на публичный IP вашей ВМ — в панели регистратора это
   поле обычно называется «A-запись» или «IPv4 address».
2. На сервере:
   ```
   sudo apt-get install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d ваш-домен.ru
   ```
3. Certbot сам допишет nginx-конфиг и получит бесплатный сертификат
   Let's Encrypt, обновляющийся автоматически. Терминал станет доступен по
   `https://ваш-домен.ru`.

## Как обновить терминал позже

Правок в код будет достаточно много — например, если я пришлю новую версию.
Порядок: перезалейте изменённую папку `backend` через WinSCP (она перепишет
файлы, кроме базы — правило `--exclude` в скрипте её бережёт), затем на
сервере:

```
sudo bash /opt/treasury/backend/deploy/setup.sh /home/yc-user/backend
```

Скрипт идемпотентен: повторный запуск обновляет код и зависимости, не трогая
базу и пароль.

## Проверка и диагностика

**Терминал работает?**
```
sudo systemctl status treasury
```
Строка `active (running)` — всё в порядке.

**Что-то не так — смотрите журнал:**
```
sudo journalctl -u treasury -n 80 --no-pager
```

**nginx не пускает:**
```
sudo nginx -t
```
Покажет, в какой строке конфига ошибка.

**Открывается, но «Bad Gateway».** Терминал (служба `treasury`) не запущен —
`sudo systemctl restart treasury`, затем смотрите журнал.

**Нет данных на странице.** Нажмите «Собрать данные» в терминале и подождите
около 15 секунд — как и при локальном запуске.

## Что важно понимать

**Резервных копий базы облако не делает само.** `treasury.db` живёт на диске
ВМ; если хотите подстраховаться — скачивайте файл через WinSCP время от
времени, или настройте снапшоты диска в консоли Yandex Cloud (платно,
отдельная строка в тарифах).

**Обновления безопасности Ubuntu — на вас.** Раз в месяц имеет смысл зайти по
SSH и выполнить `sudo apt-get update && sudo apt-get upgrade -y`.

**Роли и вход работают так же, как при локальном запуске** — см. раздел
«Вход и роли» в `README.md`. Себе оставьте `admin`, остальным заводите
пользователей с ролью «Просмотр» или «Сделки и лимиты» на вкладке «Настройки».
